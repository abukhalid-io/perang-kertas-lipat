# Perang Kertas Lipat 📄💥

Game 2 pemain di satu layar (mouse & touchscreen) yang mensimulasikan permainan kertas lipat klasik anak sekolah — tapi dalam 3D nyata pakai Three.js.

## Cara main

1. Isi nama kedua pemain & atur jumlah pasukan (maks 10) di layar awal.
2. Tiap pemain menaruh stickman-nya sendiri di sisi kiri (Pemain 1) atau kanan (Pemain 2) kertas — kedua sisi kelihatan, tidak disembunyikan.
3. Bergantian: klik/ketuk sisimu sendiri untuk membidik titik bom, lalu tekan tombol **🚀 Luncurkan Bom**.
4. Kertas 3D akan terlipat secara realistis ke sisi lawan. Kalau bom mendarat tepat kena badan stickman lawan → **KENA** (1 poin, muncul lubang gosong + efek ledakan). Meleset tetap melubangi kertas, cuma tidak dapat poin.
5. Pemain pertama yang menghabisi semua stickman lawan, menang — lengkap dengan confetti kertas dan stickman yang tersisa berjoget gembira.

## Fitur

- Animasi lipat kertas 3D (Three.js) dengan efek melengkung & memantul yang realistis
- Efek suara disintesis langsung di browser (tanpa file audio eksternal)
- Stickman dengan variasi acak: polos, pakai topi, bawa pedang, atau bawa senapan
- Mendukung mouse maupun layar sentuh
- Tombol layar penuh & prompt otomatis untuk memutar ke landscape di HP
- Satu file HTML mandiri — tidak perlu instalasi apa pun

## Menjalankan

Buka `index.html` langsung di browser, atau mainkan online lewat GitHub Pages (lihat tab **About** di repo ini untuk link-nya).
