📋 Cara main

  1. Atur dulu jumlah pasukan (maks 10). Pemain 1 taruh stickman di sisi kiri, Pemain 2 di sisi kanan — keduanya kelihatan, tidak disembunyikan.
  2. Bergantian: klik/ketuk sisimu sendiri untuk membidik titik bom, lalu tekan tombol 🚀 Luncurkan Bom.
  3. Kertas otomatis terlipat ke sisi lawan — kalau bom mendarat pas kena stickman, itu KENA 💥 (1 poin). Meleset 💧 = giliran pindah.
  4. Duluan menghabisi semua stickman lawan = menang!
